# Content Planner — интерактивные макеты

Статическая версия для GitHub Pages: контент-планер и выбор сообществ VK.
Все данные вымышлены. Авторизации, токенов, реальных групп, публикаций и backend в этом репозитории нет.

Публикуется только site/ через GitHub Actions. Исходный локальный проект остаётся отдельно.
