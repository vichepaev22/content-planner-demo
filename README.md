# Content Planner — интерактивные макеты

Статическая версия для GitHub Pages: контент-планер и выбор сообществ VK.
Планер и vk-demo используют вымышленные данные. vk-connect подключает реальный вход через собственное приложение VK ID 54867924; токен хранится только в памяти страницы. Доступ groups и чтение API проверяются отдельно. Добавлена тестовая отправка текста сейчас или в нативные отложенные VK через wall.post. Нужны фактический доступ wall и подходящий ключ VK. Постоянного worker и backend в этом репозитории нет.

Публикуется только site/ через GitHub Actions. Исходный локальный проект остаётся отдельно.
