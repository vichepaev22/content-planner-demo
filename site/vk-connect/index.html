01 / Вход

Авторизация VK ID

Пароль и код подтверждения вводятся только на странице VK. Для входа используется ваше приложение Content Planner.

Токен хранится только в памяти этой страницы. Перезагрузка или закрытие удаляет сеанс. Refresh token не сохраняется; фоновой публикации пока нет.

Что запрашивается

Первый вход — базовые сведения VK ID. Для чтения групп нужен отдельный доступ groups. Его наличие проверяется по ответу VK, а не по успешному входу.

Официальный SDK VK может выполнять служебные запросы и использовать свои cookies. Сайт не подключает свою аналитику. SDK зафиксирован на версии 2.6.10.
