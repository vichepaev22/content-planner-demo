Токен хранится только в памяти этой страницы. Перезагрузка или закрытие удаляет сеанс. Refresh token не сохраняется. Для входа в этой вкладке временно сохраняются только одноразовые PKCE/state на 10 минут; после возврата они удаляются.

Если браузер не получает список VK, запустите свой локальный коннектор и откройте Content Planner на компьютере. Токен останется в локальном процессе.

Что запрашивается

Вход запрашивает базовые сведения VK ID и доступ к вашим сообществам. Право wall для отправки записей подключается отдельно. Фактические возможности проверяются по ответу VK.

Официальный SDK VK может выполнять служебные запросы и использовать свои cookies. Сайт не подключает свою аналитику. SDK зафиксирован на версии 2.6.10.
