Для просмотра достаточно нажать кнопку выше.

Как подключить реальный VK

Для настоящего входа подготовлен отдельный локальный модуль. В нём задаётся публичный ID собственного приложения, а пароль вводится только на странице VK. GitHub Pages показывает статические макеты; сервер входа здесь не запущен.

В этом макете нет аккаунта или токена. Данные списка вымышлены и хранятся только в памяти страницы.
