# Content Planner: техническое описание обработки данных

Версия 31.10.2026, локальный пилот для владельца аккаунта VK.
Это описание фактического поведения кода. Для использования как собственной
публичной политики необходимо добавить реальные реквизиты и контакт владельца,
выбрать применимые условия и утвердить текст. Эти сведения не выдумывались.

## Назначение

Добровольный вход через VK ID и просмотр доступных пользователю сообществ:
групп, публичных страниц и событий. Доступ к публикации записей отсутствует.

## Какие данные обрабатываются

- Публичный ID зарегистрированного приложения: сохраняется на этом компьютере
  в конфигурации сервера и отображается в настройке.
- Авторизационный код и данные проверки PKCE/state: используются для обмена
  на сеанс, затем не сохраняются как журнал. Попытка входа одноразовая и
  истекает через десять минут. URL возврата сразу очищается перенаправлением.
- Access token VK и ID пользователя: только в памяти локального Node-процесса,
  до срока VK, но максимум четыре часа, либо до выхода/перезапуска. Refresh
  token не используется и не сохраняется.
- Сведения сообществ: числовой ID, название, тип, признак/уровень роли,
  количество участников при наличии. Только в памяти текущего сеанса и
  отображении страницы. Локального экспорта и записи каталога на диск нет.
- В браузере: непрозрачный идентификатор сеанса в HttpOnly/SameSite=Lax cookie.
  В localStorage и sessionStorage модуль ничего не пишет. Access token
  JavaScript страницы не получает. Страница передаёт CSRF-токен для локальных
  действий; этот токен не предоставляет доступ к API VK.

## Передача и удаление

Пароль получает официальный VK; Content Planner не имеет поля его ввода.
Обмен кода и чтение выполняются по HTTPS на официальных адресах VK.
Сервис слушает 127.0.0.1 на порту 80, а не сетевые интерфейсы компьютера.
Локальная страница работает по HTTP в пределах loopback; HTTPS в этом пилоте
не настраивается. Cookie не имеет Secure на этом HTTP-адресе.
Аналитика, внешние шрифты и сторонние CDN отсутствуют. Фото профиля не загружается.
Логи сервера не содержат URL запросов, токенов, кодов или ответов провайдера.

Выход и перезапуск очищают данные сеанса в памяти. Это не команда отзыва
разрешения приложения на серверах VK; владелец может отозвать его в настройках
VK. Конфигурацию публичного ID можно удалить вместе с файлом
`.secrets/vk-connect-client.json` при остановленном сервере.

Локальное HTTP-приложение рассчитано на доверенный компьютер одного владельца.
Настоящая многопользовательская или публичная эксплуатация требует отдельной
архитектуры, домена/HTTPS, управления доступом и утверждённых документов.
